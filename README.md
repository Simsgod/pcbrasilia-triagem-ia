# pcbrasilia-triagem-ia
Mod02_Disc01_Aula02_Atividade02
Este projeto compõe a atividade 2, aula 2, da disciplina Fundamentos de Deep Learning & Prompt Engineering.
Sua arquitetura apoia-se no usuário, Streamlit Web App, modelo de ML, Mini-RAG e respsta inteligente.
O objetivo é triar as ocorrências registradas e classificá-las por prioridade baixa, média e alta.
Ela também permite envios de perguntas para obter orientações sobre procedimentos.
